## What was NOT built, and why — `sellerInfo.ts` and `blockedSet.ts`
These two query Mart database tables (`MartListing`, `MartSellerRating`, `MartBlock`, `MartFollow`) that don't exist in the schema yet — that's Step 0.8, which comes later in the build plan's own numbering even though these helpers logically depend on it. Writing them now would either not compile (Prisma Client has no types for tables that don't exist) or require faking the dependency. **Decision: build the schema-independent half of 0.6 now, defer `sellerInfo.ts` and `blockedSet.ts` until immediately after Step 0.8.** Logged in `docs/mart/DECISIONS-MADE.md`.

## Other decision made while building
`mobile/src/utils/martHelpers.ts`'s `timeAgo()` reuses the app's existing `notifications.justNow` / `notifications.minsAgo` / `notifications.hoursAgo` / `notifications.yesterday` / `notifications.daysAgo` i18n keys (same wording as `NotificationsScreen.tsx`'s own local `timeAgo()`) instead of adding duplicate Mart-specific keys — same relative-time semantics either way, and the app already translates these into si/ta.
