## Two things caught and fixed before testing
1. **Routing mistake**: the rules-accept route was first written inside `me.ts`, which would have put it at `/mart/me/rules/accept` instead of the spec's `/mart/rules/accept`. Moved to its own file mounted at the correct path before this ever ran.
2. **A real bug**: the first draft of the `unreadThreads` count had `lastMessageSenderPhone` as two separate keys in the same `where` object — in JavaScript, the second one silently overwrites the first, so one of the two intended conditions was just dropped. Caught on re-read before testing. Deeper issue found at the same time: "unread" correctly requires comparing `lastMessageAt` against whichever of `ownerReadAt`/`otherReadAt` applies to me in that thread — Prisma can't compare two columns of the same row without raw SQL, and no Chat UI exists yet to verify such a query against real data anyway. **Decision: `unreadThreads` returns `0` for now, with a clear comment explaining why, real logic deferred to Milestone 1 Step 1.8 (Chat) when there's something real to test it against.** Logged in `docs/mart/DECISIONS-MADE.md`.
