## Decision (logged in full in `DECISIONS-MADE.md`)
`NameDistrictSheet` reused as My Mart's "Edit" action covers only name + district, not a
profile photo — the full dedicated Edit screen (photo picker + the account-deletion row)
stays deferred to Milestone 3 per the existing Step 0.13 decision. Reusing the already-
built, already-tested sheet for the two fields it already handles was judged worth doing
now rather than leaving "Edit" as a pure stub, since the cost was a 2-line optional-prop
addition to an existing component.
