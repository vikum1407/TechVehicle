# Step 0.11 — Mart tab + navigation — verification

Date: 2026-10-09.

## What was built
- `mobile/src/screens/MartNavigator.tsx` — Mart's own, fully self-contained internal screen stack (`push`/`pop`), separate from `App.tsx`'s global `Screen`/`backMap` system entirely. `App.tsx` only knows about **one** new screen value, `'mart'`; everything Mart-internal happens inside this component. Right now it only has one destination (`'home'`, rendering the Step 0.10 `MartDevPreviewScreen` — the real Mart Home screen is Milestone 1 Step 1.3; `push`/`pop` are already wired in so that screen plugs straight in later without reshaping this file).
- `MartNavigator` registers its own `BackHandler` listener while mounted. React Native calls the most-recently-registered listener first; since this listener is added when `MartNavigator` mounts (after `App.tsx`'s own root listener already exists), a hardware back-press on a Mart screen is intercepted here first — pops the Mart stack if it has more than one entry, otherwise returns `false` and lets the press fall through unchanged to `App.tsx`'s existing listener (which now has one new entry, `mart: 'vehicles'`).
- `mobile/src/config/api.ts` — new `getAppConfig()`, matching `03-api.md` §1 exactly: optional auth, never throws (falls back to `martEnabled: false` on any failure, per the spec's own rule that a failure here must never block the app).
- `App.tsx` — one new `Screen` union member, one new array entry each in `TAB_SCREENS`/`NO_HOME_SCREENS`, one new `useState`, one new effect (fetches `/app-config` on launch and again after login, from the same effect, using the `token` dependency), one new `backMap` key, one new conditional render block, and the `BottomTabBar` call gets 2 new/widened props. **Nothing existing was deleted or changed — see the diff review below.**
- `mobile/src/components/BottomTabBar.tsx` — `Tab` type widened, one new optional prop (`showMartTab`, defaults `false` so no existing caller's behavior changes), one new conditional tab block added after the existing two. The existing `vehicles`/`garage` tab blocks are byte-identical to before.
