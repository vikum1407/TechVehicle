# Mart designs (PNG exports)

These are screenshots of the finished design boards (390x844 phone frames). Placeholder gray squares are photos. Boards are fixed at one screen height, so a long form (for example Post Ad) is cut off at the bottom; the screen spec describes the rest.

**If a picture and `04-screens.md` disagree, the written spec wins.** Mockup-only aids (the chat Preview strip, demo selections, fake data) must be ignored.

`chosen/` has the direction Vikum picked for each screen. `alternatives/` has the options that were not picked (kept only for reference; do not build them).
